# LoginMaster - Sistema Administrativo

LoginMaster es un sistema administrativo web desarrollado en HTML, CSS y JavaScript para gestionar clientes, productos y proveedores. El proyecto está pensado como una solución funcional para una presentación académica, con autenticación básica, dashboard, CRUD y persistencia en LocalStorage.

---

## 🚀 Funcionalidades principales
- Autenticación de usuarios con validación de credenciales.
- Roles diferenciados:
  - Administrador: acceso completo y visualización de indicadores avanzados.
  - Operador: acceso restringido, sin eliminación de registros.
- Dashboard con menú lateral, encabezado, tarjetas de resumen y gráficos.
- CRUD para clientes, productos y proveedores.
- Persistencia de datos con LocalStorage.
- Importación y exportación de datos en Excel y JSON.
- Modo oscuro/claro y diseño responsive.

## ▶️ Cómo usar el proyecto
1. Abrir el archivo index.html en un navegador o servir la carpeta con un servidor local.
2. Iniciar sesión con una de las credenciales de prueba.
3. Gestionar clientes, productos y proveedores desde el dashboard.
4. Usar los botones de importación/exportación para respaldar o restaurar datos.

---

## 📂 Estructura del proyecto
- index.html: pantalla de login.
- dashboard.html: interfaz principal del sistema.
- css/: estilos del login, dashboard y tema.
- js/: lógica de autenticación, dashboard, módulos CRUD, importación/exportación y tema.
- docs/: documentos de prompts y datos de ejemplo.

---

## 📝 Notas para la presentación

- Los datos se conservan en LocalStorage al recargar la página.
- La interfaz está pensada para verse moderna y profesional durante la exposición.
